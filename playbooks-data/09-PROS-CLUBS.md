# PLB-PRC-037 - Demande Pros & Clubs (tarifs / devis / partenariat)

## 1. 🎯 Objectif

Qualifier une demande "pro" (entreprise, association, club) et orienter vers le bon canal de traitement.

---

## 2. 🗂️ Métadonnées

| Propriété          | Valeur                                                                                |
| ------------------ | ------------------------------------------------------------------------------------- |
| **Identifiant**    | PLB-PRC-037                                                                           |
| **Catégorie**      | 7. AUTRES QUESTIONS                                                                   |
| **Sous-catégorie** | 7.5 Toutes autres demandes                                                            |
| **Tags Clés**      | `pro`, `professionnel`, `club`, `association`, `collectivité`, `devis`, `partenariat` |
| **Priorité**       | P2                                                                                    |

---

## 3. 🔎 Conditions de Déclenchement

L'agent doit s'activer si le client demande :

- Des tarifs pros / remises / conditions spécifiques
- Un devis
- Un partenariat club / association
- Une facturation au nom d'une structure

**Exemples de formulations clients :**

- "Je suis un professionnel, avez-vous des tarifs pro ?"
- "Nous sommes un club, pouvons-nous avoir un partenariat ?"
- "Pouvez-vous nous faire un devis ?"
- "Je veux acheter en quantité pour mon entreprise"

---

## 4. 📋 Informations à Identifier dans l'email

- Nom de la structure (entreprise / club / association)
- Nom + prénom du contact
- Email + téléphone
- Ville / code postal
- SIRET (si entreprise) / n° d'association (si disponible)
- Nature de la demande : devis / volume / type de produits / échéance
- Montant estimé / quantité (si connu)

---

## 5. ✅ Décision (GO/KO)

| Situation constatée                                                                | Décision | Suite à donner                                                                |
| ---------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------- |
| Demande d'information générale (existence d'une offre pros/clubs, étapes à suivre) | **GO**   | Expliquer qu'une étude est nécessaire et demander les infos listées ci-dessus |
| Demande de remise/tarif personnalisé / devis / partenariat nécessitant validation  | **KO**   | **Handoff vers un conseiller** (traitement dédié) + collecter les infos       |
| Demande urgente avec contexte sensible (événement imminent, volume important)      | **KO**   | **Handoff vers un conseiller** (prioriser) + collecter les infos              |
