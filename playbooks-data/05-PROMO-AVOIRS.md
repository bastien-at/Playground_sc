# PLB-025 - Code promo ne fonctionne pas

## 1. 🎯 Objectif

Aider le client à comprendre pourquoi son code promo ne fonctionne pas et lui proposer des solutions.

---

## 2. 🗂️ Métadonnées

| Propriété          | Valeur                                                                       |
| ------------------ | ---------------------------------------------------------------------------- |
| **Identifiant**    | PLB-025                                                                      |
| **Catégorie**      | 7. AUTRES QUESTIONS                                                          |
| **Sous-catégorie** | 7.5 Toutes autres demandes                                                   |
| **Tags Clés**      | `code promo`, `réduction`, `ne fonctionne pas`, `code invalide`, `promotion` |
| **Priorité**       | P2                                                                           |

---

## 3. 🔎 Conditions de Déclenchement

L'agent doit s'activer si le client a un problème avec un code promo.

**Exemples de formulations clients :**

- "Mon code promo ne marche pas"
- "Le code est refusé"
- "La réduction ne s'applique pas"

---

## 5. 💬 Gabarits de Réponse

### 5.1. Réponse Standard

```
Bonjour [Prénom],

Si votre code promo ne fonctionne pas, vérifiez les points suivants :

**✅ Vérifications à faire :**
- Le code est saisi correctement (sans espace avant/après)
- La date de validité n'est pas dépassée
- Le montant minimum d'achat est atteint
- Les produits du panier sont éligibles à l'offre

**⚠️ Restrictions importantes :**
- **Un seul code promo par commande**
- Les produits des **vendeurs partenaires ne sont JAMAIS éligibles** aux codes promo Alltricks
- Un code oublié lors de la validation ne peut pas être appliqué après coup

**🔗 Codes promo officiels Alltricks :**
https://www.alltricks.fr/surl/codespromos

Les codes trouvés sur des sites tiers peuvent être expirés ou non valides.

L'équipe Alltricks
```

---

## 6. ⚠️ Règles et Points d'Attention

**Points clés FAQ :**

- Un seul code par commande
- Produits partenaires jamais éligibles
- Code oublié = non récupérable après validation
- Codes tiers non garantis

---

```

- Les avoirs **n'ont pas de date d'expiration**
- Utilisables **en plusieurs fois**
- **Cumulables entre eux**

- Utilisables **en magasin** également

L'équipe Alltricks
```

# PLB-028 - Cumul des remises

## 1. 🎯 Objectif

Clarifier les règles de cumul des différentes remises.

---

## 2. 🗂️ Métadonnées

| Propriété          | Valeur                                                       |
| ------------------ | ------------------------------------------------------------ |
| **Identifiant**    | PLB-028                                                      |
| **Catégorie**      | 7. AUTRES QUESTIONS                                          |
| **Sous-catégorie** | 7.5 Toutes autres demandes                                   |
| **Tags Clés**      | `cumuler`, `cumul`, `plusieurs codes`, `remise`, `réduction` |
| **Priorité**       | P3                                                           |

---

## 5. 💬 Gabarits de Réponse

### 5.1. Réponse Standard

```
Bonjour [Prénom],

Voici les règles de cumul chez Alltricks :

**✅ Ce qui est CUMULABLE :**
- Plusieurs **avoirs** entre eux
- Plusieurs **chèques-cadeaux** entre eux
- **Avoir + chèque-cadeau** sur une même commande

**❌ Ce qui n'est PAS cumulable :**
- Plusieurs **codes promo** (1 seul par commande)
- **Code promo + autre code promo**

**💡 Astuce :**
Les codes promo et les avoirs sont de nature différente :
- Code promo = réduction sur le montant
- Avoir = crédit à utiliser comme moyen de paiement

L'équipe Alltricks
```

---

## 6. ⚠️ Règles et Points d'Attention

**Points clés FAQ :**

- 1 seul code promo par commande
- Avoirs et chèques-cadeaux cumulables
- Avoir ≠ code promo
- Codes anniversaire Alltricks+ : voir PLB-008 (08-ALLTRICKS+.md)
