## 4. Termes retours et remboursements

### Types de retour

| Terme officiel          | Définition                  | Délai                   |
| ----------------------- | --------------------------- | ----------------------- |
| **Retour standard**     | Retour dans le délai légal  | 30 jours                |
| **Retour Alltricks+**   | Retour avec abonnement      | 100 jours               |
| **Retour en magasin**   | Dépôt en boutique Alltricks | Gratuit                 |
| **Retour hors-gabarit** | Produit > 30kg ou > 150cm   | Transporteur spécifique |

### Processus retour

| Terme officiel               | Définition                       |
| ---------------------------- | -------------------------------- |
| **Étiquette de retour**      | Document à coller sur le colis   |
| **Preuve de dépôt**          | Ticket remis par le point relais |
| **Traitement du retour**     | Vérification à réception         |
| **Création d'avoir**         | Génération du crédit client      |
| **Demande de remboursement** | Transformation avoir → argent    |
| **Frais de retour**          | Coût déduit de l'avoir           |

### Délais standardisés

| Processus           | Délai officiel         |
| ------------------- | ---------------------- |
| Acheminement retour | 5 à 7 jours ouvrés     |
| Traitement retour   | 72 heures maximum      |
| Remboursement       | 5 jours ouvrés maximum |
| Apparition CB       | + 2 à 3 jours ouvrés   |

## 11. Termes interdits / à éviter

| ❌ Terme à éviter | ✅ Utiliser plutôt                   | Raison               |
| ----------------- | ------------------------------------ | -------------------- |
| Marketplace       | Vendeur partenaire                   | Terme interne        |
| Seller            | Vendeur partenaire                   | Anglicisme           |
| Refund            | Remboursement                        | Anglicisme           |
| SAV               | Garantie / Service après-vente       | Trop technique       |
| Litige            | Réclamation                          | Connotation négative |
| Réclamation       | Demande                              | Plus neutre          |
| Problème          | Situation / Question                 | Plus positif         |
| Malheureusement   | Si possible, reformuler positivement | Ton négatif          |
| Impossible        | "Voici l'alternative..."             | Ton négatif          |
